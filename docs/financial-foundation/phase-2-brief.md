# Future goal slider — requirements only

Implement only after the simplified financial foundation is approved and deployed.

Retain the existing goal slider and conversion/AOV What-If Modeller. Propose three markers: Match Last Year, Main Goal, Ambitious Goal. Each needs its own target amount, lock, agreed revenue basis and progress figures. Missing comparable prior-year data must withhold Match Last Year. Owners must approve the Ambitious target and any All Stores seasonal forecast.

Allow unlocked markers to move together or individually; locked markers remain fixed. Keep approved shared targets distinct from local What-If values. Reset restores approved values. Preserve historical definitions and a rollback reference. No cost-entry panels or additional dashboards are proposed here.

This PR contains no implementation of the three-marker design. PR21 retains the archived scenario prototype for possible future reuse.
